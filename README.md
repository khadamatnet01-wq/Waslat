# وصلت - أكتور سحب الإعلانات العقارية

أكتور Apify مخصّص لاستخراج إعلانات العقارات من موقع **وصلت السعودي** (wasalt.sa) بكامل تفاصيلها.

---

## الحقول المُستخرجة

| الحقل | الوصف |
|---|---|
| `title` | عنوان الإعلان |
| `price_sar` | السعر بالريال السعودي |
| `property_type` | نوع العقار (شقة، فيلا، أرض...) |
| `listing_type` | بيع أو إيجار |
| `city` | المدينة |
| `district` | الحي |
| `address` | العنوان الكامل |
| `area_sqm` | المساحة بالمتر المربع |
| `bedrooms` | عدد غرف النوم |
| `bathrooms` | عدد دورات المياه |
| `phone` | رقم الجوال |
| `owner_name` | اسم المعلن |
| `owner_type` | نوع المعلن (وسيط، فرد...) |
| `rega_license` | رقم ترخيص هيئة العقار |
| `is_verified` | هل العقار موثّق؟ |
| `posted_at` | تاريخ النشر بالعربي (توقيت الرياض) |
| `posted_at_iso` | تاريخ النشر بصيغة ISO |
| `updated_at` | تاريخ آخر تحديث |
| `has_image` | هل يحتوي على صور؟ |
| `images` | روابط الصور |
| `url` | رابط الإعلان |

---

## مثال على الإدخال

```json
{
    "search": "شقة",
    "city": "الرياض",
    "cityId": 273,
    "listingType": "sale",
    "propertyType": "residential",
    "maxResults": 50
}
```

---

## ملاحظات

- يُنصح باستخدام **Residential Proxy** لتجنب الحجب.
- الحد الأقصى للنتائج 200 عقار لكل تشغيل.
- وقت النشر يظهر بتوقيت **منطقة الرياض (Asia/Riyadh)**.
